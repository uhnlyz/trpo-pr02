# Ответы к защите практической работы № 2

**Что является источником данных?** Файл `dataset/catalog.csv` с полями id, name, category, price, rating. В `dataset/theme.json` хранятся параметры оформления. Изображения доступны в `dataset/assets/`.

**Как данные попадают в интерфейс?** Карточки в `index.html` заполнены вручную из 18 строк CSV; скрипт для загрузки данных не требуется.

**Какие средства CSS используются?** CSS Grid для размещения каталога и карточек, Flexbox для шапки, внутренних элементов карточек и панели информации. Медиазапросы адаптируют страницу под ширины меньше 900 px и 560 px.

**Зачем SCSS?** Для переменных темы, разделения стилей по модулям, повторно используемого миксина `container` и функции `spacing`, которая рассчитывает отступы на основе единой переменной.

**Как собрать проект?** Установить Node.js и выполнить `npm install`, затем `npm run build:css`. Для автоматической пересборки `npm run watch:css`. Для простого просмотра можно сразу открыть `index.html`.

**Чем отличается HTML от CSS?** HTML определяет структуру и содержание страницы, CSS — цвета, размеры, отступы и расположение.

**Почему нет JavaScript?** Здесь статический каталог; содержание берётся из CSV при подготовке страницы. Пункты меню переходят к нужным разделам, не выполняя фильтрацию.

**Что проверялось вручную?** Отображение карточек и SVG, наличие всех 18 товаров, мобильная и планшетная сетки, корректность внутренних ссылок.

**Как развивать проект?** При увеличении объёма данных можно динамически создавать карточки, добавить поиск и фильтрацию через JavaScript, а данные получать из API.
