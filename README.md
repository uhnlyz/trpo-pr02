# Практическая работа № 2 — CSS, адаптивная вёрстка и SCSS

## О проекте
Учебный каталог из **18 товаров**, созданный на HTML, CSS и SCSS. Данные перенесены из `dataset/catalog.csv` без изменения названий, категорий, цен и рейтингов. Тема соответствует `dataset/theme.json`.

## Открытие
Откройте файл `index.html` в браузере. Готовый `css/styles.css` уже включён в репозиторий.

## Компиляция SCSS
Нужен Node.js (LTS). В каталоге проекта:
```bash
npm install
npm run build:css
```
Для слежения за изменениями:
```bash
npm run watch:css
```

## Структура
- `index.html` — 18 карточек с семантическими HTML-тегами.
- `dataset/catalog.csv` — исходные данные карточек.
- `dataset/theme.json` — значения цветов, радиуса и отступов.
- `dataset/assets` — исходные SVG-изображения.
- `images` — изображения, используемые страницей.
- `scss/_variables.scss` — переменные и функция `spacing`.
- `scss/_mixins.scss` — миксин `container`.
- `scss/_base.scss` — базовые стили.
- `scss/_layout.scss` — сетки, шапка, блоки и адаптивность.
- `scss/_components.scss` — карточки, меню, кнопки.
- `scss/styles.scss` — входная точка Sass.
- `css/styles.css` — готовые стили для браузера.
- `docs/answers.md` — ответы для защиты.

## Проверка
Проверьте страницы при ширинах **375, 768, 1440 px**, наличие 18 карточек, изображения, ссылки на разделы и адаптивность. Используются **CSS Grid**, **Flexbox**, две контрольные точки: **900 px и 560 px**.

## Примечание
Это статическая учебная страница без JavaScript. Пункты категорий переводят к соответствующему разделу, а не скрывают другие товары.
