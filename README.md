# Практическая работа № 2
### CSS, адаптивная вёрстка и SCSS. Организация стилей

**Учебный каталог** — адаптивная страница с 18 карточками товаров, сгруппированными по трём категориям: книги, курсы и инструменты. Основное внимание уделено CSS Grid, Flexbox и модульной структуре SCSS.

## Реализованные элементы

- Каталог из 18 карточек с названиями, ценами и рейтингами.
- Переходы к категориям с помощью якорной навигации.
- Сетка CSS Grid и Flexbox для элементов интерфейса.
- Адаптивное отображение в три, две и одну колонку; контрольные точки — **900 px** и **560 px**.
- SCSS-переменные темы, миксин контейнера, функция расчёта отступов и стили компонентов.
- SVG-иллюстрации товаров.

## Данные и оформление

Значения для карточек взяты из `dataset/catalog.csv`. Параметры цветовой схемы и отступов соответствуют `dataset/theme.json` и перенесены в SCSS-переменные. Данные представлены в HTML; динамическая загрузка и фильтрация JavaScript не используются.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `index.html` | Разметка каталога |
| `css/styles.css` | CSS для браузера |
| `scss/_variables.scss` | Переменные и функция `spacing()` |
| `scss/_mixins.scss` | Миксин `container` |
| `scss/_base.scss` | Базовые стили |
| `scss/_layout.scss` | Сетки и адаптивная вёрстка |
| `scss/_components.scss` | Стили карточек и элементов управления |
| `scss/styles.scss` | Точка входа Sass |
| `dataset/`, `images/` | Данные и иллюстрации |

## Запуск и сборка

Готовая страница доступна через `index.html` без дополнительных зависимостей.

Для компиляции SCSS требуется **Node.js**. Команды из корня проекта:

```bash
npm install
npm run build:css
```

Для автоматической пересборки при изменении исходных SCSS-файлов:

```bash
npm run watch:css
```

Результат компиляции сохраняется в `css/styles.css`.
